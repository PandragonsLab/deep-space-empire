# Dimensional Explorer

An epic text-based explorer/idler game where you journey through infinite dimensional realities, discovering new locations, collecting resources, and unraveling the mysteries of existence.

## Features

- **Deep Idle Mechanics**: Resources generate automatically while you're away
- **Exploration System**: Discover new dimensional locations with unique properties
- **Compound Progression**: Multiple upgrade paths that synergize with each other
- **Achievement System**: Track your progress and unlock rewards
- **Save/Load**: Persistent progress with offline generation
- **Steam Ready**: Built with Electron for easy Steam deployment

## Quick Start

### Development Setup

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run in Development Mode**
   ```bash
   npm run dev
   ```
   This starts the server on http://localhost:3000

3. **Run as Electron App**
   ```bash
   npm run electron-dev
   ```

### Building for Distribution

1. **Build for Desktop**
   ```bash
   npm run dist
   ```

2. **Package for Steam**
   ```bash
   npm run build
   ```

## Game Mechanics

### Resources
- **Energy**: Generated by Energy Harvesters, used for exploration and purchases
- **Matter**: Condensed by Matter Condensers, required for advanced upgrades
- **Knowledge**: Extracted by Knowledge Probes, unlocks deeper game systems

### Exploration
- **Manual Exploration**: Spend 10 Energy to advance progress toward next discovery
- **Automatic Progress**: Exploration advances automatically based on your exploration speed
- **Location Discoveries**: Each new location provides unique bonuses and unlocks new possibilities

### Progression Systems
- **Collectors**: Automated resource generators that work while offline
- **Upgrades**: Permanent improvements to efficiency, speed, and multipliers
- **Achievements**: Milestone rewards that provide recognition for progress

## Technology Stack

- **Backend**: Node.js + Express + Socket.io
- **Frontend**: Vanilla HTML5/CSS3/JavaScript
- **Desktop**: Electron
- **Steam Integration**: Steamworks SDK (when implemented)

## Steam Integration

The game is prepared for Steam integration with:
- Electron packaging for desktop distribution
- Achievement system ready for Steam achievements
- Stats tracking for Steam leaderboards
- Save system compatible with Steam Cloud

To add Steam integration:
1. Install `steamworks.js` package
2. Uncomment Steam code in `main.js`
3. Add your Steam App ID
4. Configure Steam achievements and stats
